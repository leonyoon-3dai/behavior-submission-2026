# Results package

**3 tasks · 12 rollouts · 26 files · 18.5 KiB**

Explore the final self-evaluation of Ilia + EXPO-RT on tasks 001, 002, and 005, each run once on public instances 0–3. This small ZIP preserves all twelve outcomes and the records needed to understand how they were evaluated.

## What's inside

| Included | What you can inspect |
|---|---|
| 12 original metric files | Each rollout's evaluator output in `metrics/*.json` |
| Result summaries | Final goal progress, success, and step counts in `results.csv` and `results.json` |
| Evaluation setup | R1Pro robot configuration and complete evaluation wrapper source |
| Reproduction records | Model and execution manifests, container identity, and deployment checks |
| Guides and video index | Instructions and links to the original rollout videos |

Preview the [CSV table](results/results.csv) or [JSON summary](results/results.json) here before downloading.
